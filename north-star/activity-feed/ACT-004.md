# ACT-004 — Home Today activity checklist

Issue: [#249](https://github.com/vokerg/chess_repertoir_trainer/issues/249)

Status: COMPLETE

## Home integration

The signed-in Home page now places one compact Today section immediately after Continue and before Recommended next. The widget reads only the shared ACT-001 `TodayActivityResponse`; Angular does not submit completion events or recreate server goal definitions.

A public `features/activity-feed` boundary owns the typed HTTP service and contract type exports. `HomeDashboardStore` remains the page workflow owner. It stores the source DTO, maps it into a Home-specific immutable view model, and exposes isolated loading, error, notice, and retry state to one standalone OnPush presentational component.

## Experience and accessibility

The five server goals render as native disabled checkboxes with current/target counts and bounded progress bars. Checked state comes directly from each server `completed` value. The component includes overall completed-goal progress, a zero-activity explanation, a positive all-done state, stable goal tracking, responsive single-column behavior, reduced-motion handling, and a local retry action.

The rest of Home remains usable when activity fails. Activity errors do not contribute to the page-fatal error threshold and appear only inside the Today surface.

## Effective time-zone synchronization

Each Home load requests the server summary alongside the existing independent sources. When the browser reports a valid IANA time zone that differs from the summary, the store performs one preference update and reloads the summary exactly once. A failed preference update retains the usable original summary and explains which server time zone still defines the day. A failed post-update reload also retains the original summary and asks for a later refresh.

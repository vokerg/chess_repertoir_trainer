# Completion Reports

Every completed task must create a report named:

```text
RB-###-YYYY-MM-DD-<slug>.md
```

Reports are historical evidence. They explain what was actually learned or delivered and how the north-star plan changed.

A report must include:

- task and branch;
- purpose;
- delivered scope;
- excluded scope;
- repository areas inspected and changed;
- architecture and product decisions;
- validation performed and skipped;
- limitations and residual risks;
- standalone product impact;
- north-star impact;
- new tasks proposed;
- queue and roadmap recommendation.

Use `_TEMPLATE.md`.

Documentation-only work may skip application checks, but the report must say so explicitly.

## Delivered boundary

RB-013 delivers a bounded, deterministic Player Chess Profile to Repertoire Builder starting point without turning profile conclusions into constraints or persisted identity.

The integrated feature:

- derives independent White and Black suggestions only from eligible classified profile evidence;
- requires at least five classified opening-group games for a side before exposing its Builder action;
- maps weighted opening character to the existing Balanced, Solid, Aggressive, or Surprise target presets;
- carries bounded profile contract, classification, generation-time, side, evidence-count, speed, theory, persona, and coverage provenance through an expiring route snapshot;
- displays the source suggestion in Builder and provides an explicit standard-default rejection path;
- keeps the existing setup dialog as the only effective target editor;
- records profile-derived speed, objective, and coverage using the existing RB-006 `PLAYER_PROFILE` default source;
- preserves population as separate peer-resolution or explicit manual evidence;
- records manual differences through exact RB-006 `overriddenFields`;
- removes profile provenance when the user deliberately changes side;
- exposes persona character, soundness, risk, complexity, theory, and coverage dimensions rather than hiding them behind a label;
- leaves candidate profile fit and selected-target fit separate;
- adds no API calculation change, candidate-ranking policy change, Builder reducer change, course preview/apply/write change, persistence, migration, background synchronization, AI narrative, or trap integration.

Personas are accepted as route-local target presets only. They are not factual player labels, saved personas, or course/line metadata.
